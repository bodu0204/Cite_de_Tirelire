## 1. 目的

今の作り（payment-method-sync.md）は、支出に「どう払ったか」を付けて、カードの未払いを手元のお金の推測（E7）に足すだけだった。実際のお金は、次のように**置き場所の間を動く**。

| 動き | 例 |
|---|---|
| 収入 | 給料が口座Aに入る |
| 支出 | 財布Aの現金でランチ、クレカAで本、Suica で電車 |
| 振替 | ATM で口座A → 財布A、口座A → Suica にチャージ、クレカの引き落とし 口座A → クレカA、口座A → 口座B（貯金用） |

本書では、口座A・口座B・財布A（現金・いつもの置き場所）・財布B・クレカA・クレカB・Suica のような**置き場所ごとに残高を持ち**、収入・支出・振替の記録から残高を計算する。誤差調整は**置き場所ごとに、計算した残高と実際の残高を比べる**形にする。

- どこにいくらあるかがアプリでわかる。
- 振替の記録し忘れ（ATM で下ろした、チャージした）は、置き場所どうしの誤差が打ち消し合うので、ゲームに影響しない。
- 収入・支出の記録し忘れだけが合計の誤差として残り、今の差分の解消ルールで解消される。

## 2. 前提と用語

### 2.1 前提

| # | 前提 |
|---|---|
| H1 | 支出は使った日に記録する（発生主義）。精算・手数料・貯金額などゲームの判定は**置き場所によって変えない**（D-22 から引き継ぐ） |
| H2 | **振替はお金を増やしも減らしもしない。** ゲームの通貨（金貨・債券など）は動かさない。置き場所の残高だけを動かす |
| H3 | 置き場所の残高 ＝ 登録したときの残高（開始残高）＋ その後の記録（収入 ＋、支出 −、振替の入り ＋・出 −、誤差調整 ±） |
| H4 | クレカの残高は**マイナス（未払い）**で持つ。カードで払うとマイナスが増え、引き落とし（口座 → クレカの振替）で 0 に戻る |
| H5 | 置き場所を記入しない支出は「いつもの置き場所」（初期は財布A＝現金）から出たものとして扱う。収入は「いつもの入金先」に入る |
| H6 | 誤差調整は置き場所ごとに照合する。**照合した置き場所の誤差の合計**だけを、今の差分の解消ルール（＋は債券 → おまかせ交換、−は債券・手数料あり）で解消する |
| H7 | 貯金管理（別口座への出し入れ）は、**貯金用の置き場所への振替**にまとめる |

### 2.2 用語

| 用語 | 定義 |
|---|---|
| 置き場所 | お金がある場所。種類は 口座・現金（財布）・クレカ・電子マネー（`MoneyAccount`） |
| 開始残高 | 置き場所を登録したときの実際の残高と、その日付（開始日）。開始日より前の記録は残高に数えない |
| 振替 | 置き場所 A から B へお金を移す記録（`Transfer`）。ATM・チャージ・カードの引き落とし・口座間の送金・貯金 |
| いつもの置き場所 | 置き場所を記入しない支出が出る置き場所（1つ。初期は「財布A」） |
| いつもの入金先 | 置き場所を記入しない収入が入る置き場所（1つ。初期は最初に登録した口座、なければ財布A） |
| 貯金用 | 貯金の置き場所の印。ここへの振替が貯金の追加、ここからの振替が貯金の引出（今の貯金管理） |
| 引き落とし予定 | クレカの引き落とし日に自動で作る「口座 → クレカ」の振替の下書き。確かめて確定すると振替になる |
| 計算した残高 | H3 の式でアプリが出す残高 |
| 照合 | 置き場所の実際の残高を入れて、計算した残高との誤差を出し、残高を実際に合わせること |

## 3. As-Is（今の作り）

- 支払い方法（`PaymentMethod`：現金・クレカ・その他）を支出とサブスクに記入できる。未記入は現金。初めての記入で 10S（別枠で1日 100S まで）。
- クレカの締め日・引き落とし日から、引き落とし前の額を手元のお金の推測の E7 に足す。
- 誤差調整は、ゲームの状態から推測した手元のお金（E1〜E7 のチェックの合計）と、**合計1つの**実際の額を比べる。
- 収入に入金先がない。置き場所ごとの残高はない。
- 貯金管理は、別口座への追加・引出を金額だけ記録する（1日3回まで、100S。推測の E5 に使う）。

| # | 問題 |
|---|---|
| P1 | どの置き場所にいくらあるかがアプリでわからない |
| P2 | ATM の引き出し・チャージ・口座間の送金を記録する場所がない |
| P3 | 合計1つの額で比べるので、誤差の原因（どの置き場所の記録漏れか）がわからない |
| P4 | カードの引き落としを記録しないので、引き落とし前後の口座残高とアプリが合わない時期がある（E7 で補っているだけ） |

| RC-05 | 誤差の合計が 0 で、置き場所ごとの誤差だけあるときは、「振替の記録し忘れかもしれません（ゲームには影響しません）」と出す |
| RC-06 | 置き場所ごとの誤差が大きいとき、その置き場所の直近の記録を開いて確かめられるようにする（履歴を置き場所で絞る） |
| RC-07 | 保存した照合は、置き場所ごとの計算・実際・誤差と、誤差の合計・解消の内訳を記録に残す（`CashAdjustment`）。保存後に編集しない（ADJ-09 と同じ） |
| RC-08 | 今の手元のお金の推測（E1〜E7 のチェック・グラフ）は**廃止する**。ゲームと現実のずれは、置き場所の記録漏れ（収入・支出）として照合で解消される |
| RC-09 | 照合は、全部の置き場所をまとめて行うのを基本にする（一部だけ照合すると、振替の記録し忘れが誤差の合計に入ってしまうため）。一部だけのときは注意を出す |

> 例：ATM で口座A から 10,000 円下ろしたのを記録し忘れた。照合で 口座A −10,000、財布A +10,000 → 合計 0。ゲームには影響せず、2つの残高だけが直る。
> 例：ランチ 800 円（財布A）を記録し忘れた。照合で 財布A −800 → 合計 −800 → 債券から 800（手数料あり）。

## 10. 既存の記録と今の作りからの移行

| 項目 | 扱い |
|---|---|
| `PaymentMethod` | `MoneyAccount` に置き換える。現金 → 財布A（いつもの置き場所）、クレカ → クレカ（締め日などを引き継ぐ。引き落とし口座は未設定）、その他 → 電子マネー。開始残高は 0、開始日は移行した日 |
| 支出の支払い方法 | 出どころに引き継ぐ。開始日より前の記録なので、残高には数えない |
| 支払い方法の記入の報酬 | 受け取り済みの分はそのまま。recordKey の形（`payment:`）を引き継ぐ |
| 貯金管理の記録（`SavingsTransaction`） | 置き場所がないので振替には直さず、履歴として読むだけ残す。新しく記録はできない |
| 手元のお金の推測のチェック（`User.estimateChecks`）・E7 | 使わなくなる（RC-08）。これまでの誤差調整の記録はそのまま履歴に出す |
| 置き場所の登録の案内 | 移行後、最初に銀鉱を開いたとき「置き場所の残高を入れると、どこにいくらあるかがわかります」と、開始残高の入力に誘う（入れなければ 0 のまま使える） |

## 11. 範囲外

| 項目 | 扱い |
|---|---|
| 銀行・カード会社との連携（明細の取り込み） | しない |
| 外貨・ポイント | 扱わない。ポイントで払った分は除いて支出を記録する |
| 分割・リボ・ボーナス払い | 支出は全額で記録する。引き落とし予定の額を直して合わせ、残りは照合で直す |
| オートチャージ | 自動では作らない（振替として記録する） |
| 1つの支出を複数の置き場所で払う | しない（分けて記録する） |
| 置き場所ごとの集計・グラフ | 一覧の残高だけ。推移のグラフは今回はしない |

### 12.2 計算

- `balanceOf(account, until)`：開始残高 ＋ 開始日以後の 収入（入金先）− 支出（出どころ。取り消しは 0）＋ 振替の入り − 振替の出 ＋ 照合の調整。出どころ・入金先が null の記録は、いつもの置き場所・いつもの入金先として数える。
- 引き落とし予定は、同期（`withGame`）のたびに「引き落とし日が来た・まだ予定のない請求月」を探して作る。
- 照合の誤差の合計の解消は、今の `resolveDiff`（[resolve.ts](../src/server/resolve.ts)）をそのまま使う。

### 12.4 画面

- 銀鉱（SCR-02）のタブを **支出 / 収入 / お金の管理 / 履歴** にする。**貯金管理と誤差調整のタブは「お金の管理」にまとめる**（2026-11-15）。
  - 支出・収入：出どころ・入金先を選ぶチップ（置き場所が2つ以上のとき）。
  - お金の管理：上から **置き場所と残高**（合計・貯金管理の増減）、**クレカの引き落とし予定**、**振替**（よく使う組のボタン、出元・入れ先・金額・日付・メモ。貯金用への振替には「貯金の追加」と添える）、**予算外の入出金**、**残高を合わせる**（照合：置き場所ごとに 計算した残高・実際の残高・誤差、誤差の合計と解消のプレビュー）。
  - 履歴：収入・支出・振替・予算外の入出金・照合を日付順に。置き場所で絞れる。出どころ・入金先の変更、振替・予算外の金額の変更と取り消しもここから。
- 設定（SCR-10）：「お金の置き場所」（§4）。登録・編集・使わない・削除、いつもの置き場所・入金先・貯金用の印。
