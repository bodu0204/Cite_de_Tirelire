## 1. 概要

発展Lvの進み方は要件の目安どおり（Lv6まで17日）だが、自動発展の優先順に穴があり、公共施設・鉄道・オフィス・未来都市センターが60日間で1棟も建たない。また、貯金が街の大きさにほとんど効かず、16日目以降は街の内部経済がプレイヤーの金貨を上回る。

- **対象**：`src/game`（設定値・建物カタログ・内部経済・自動発展・通貨と交換）。
- **方法**：コードの読解と、`scripts/balance.ts` と同じ条件の60日間の放置シミュレーション。比較として、貯金を債券経由で資源として入れる場合、債券倍率 k=1.5 の場合、優先順と不足解消を変えた場合も試算した。
- **最優先の対応**：優先順（新産業を生産効率の前へ）と不足解消（電力を食料より先へ）の2点。どちらも数行の変更で、試算で効果を確かめた（§6 R-01・R-02）。
- **範囲外**：UI上の操作コストや実際のプレイヤーの行動は扱わない。金額の仮定（1日1,000円など）はその都度明記する。

## 2. ゲームシステムの整理

バランスを決めているのは「現実のお金 → 通貨 → 街の資源」と「街の内部経済」の2系統で、数値の正本は `src/game/config.ts` と `src/game/catalog.ts` にある。

**現実側から街へ入る経路**

- 金貨 G：月間自由予算 B − サブスク S − ユーザ通貨 C を収入期間で毎分配当（1G＝1円）。交換で 1G あたり木材10・石材5・食料10・都市資金10（`GOLD_RESOURCE_VALUE`）。
- 銀貨 S：収入・支出の記録 50S、貯金管理 100S、1日 300S まで。資源価値は金貨の 1/10、交換手数料 5S。
- 債券：G→債券は 1:1・無料。0〜上限（3M）に入る分は同額の金貨と同じ資源も街に入り、時間発展に倍率 k（最大1.5）が掛かる。
- 技術Lv：貯金額（債券＋ゲーム内で使った金貨）の最高到達額で 0 / 5千 / 1.5万 / 3万 / 6万 / 10万 / 20万円。

**街の内部経済**（`city/economy.ts`・`city/sim.ts`）

- 10分ティックで、人口 → 労働力（×0.7）→ 生産 → 食料消費（0.25/人・時）→ 税収（0.8/人・時 × 幸福度）→ 建設 の循環。
- 建設は優先順（不足解消 → 雇用 → 住宅 → 物流 → 効率化 → 新産業 → 景観）で自動。上位の目標が12時間以内に払えるなら下位には資金を回さない。
- 発展pt：2pt/時 × 稼働係数 × k ＋ 建設3・Lvアップ1・進化4・人口25人ごとに1。発展Lv6（1,200pt）で頭打ち。
- 係数：都市資金コスト ×2、建設時間 ×3、商工業収益 ×0.6（`TREASURY_COST_SCALE` ほか）。

**検証方法**：`scripts/balance.ts` と同じ貯金スケジュール（1日目 5千円 → 40日目 累計20万円）で、プレイヤーの交換なし・k＝1 の放置を60日間シミュレーションした。以降の数値はこの結果である。

## 3. 経済バランス

街の内部収入は60日で約2,000倍（8.7 → 17,454/時）に伸び、16日目以降はプレイヤーが入れる金貨の価値を上回る。お金が街の大きさに効くのは序盤だけで、中盤以降は木材・石材が余り、詰まるのは都市資金だけになる。

|---:|---:|---:|
| 1 | 8.7 | 0.02 |
| 4 | 14.8 | 0.04 |
| 7 | 54.2 | 0.13 |
| 10 | 142.2 | 0.34 |
| 14 | 293.5 | 0.70 |
| 16 | 428.0 | 1.03 |
| 21 | 1,019.6 | 2.4 |
| 28 | 2,435.6 | 5.8 |
| 35 | 7,342.1 | 17.6 |

| 50 | 14,506.2 | 34.8 |

1G＝都市資金10、1S＝都市資金1 で換算。銀貨の記録報酬の上限（300S/日＝12.5/時）は4日目に街の収入を下回る。

- **木材・石材は余り、都市資金だけが詰まる**：50日目の在庫は木材134万・石材99万。工場が木材・石材も生産するためである（自動化工場は基本値で木材16・石材12/時、最大111棟）。一方、都市資金は毎日ほぼ使い切る。木材・石材に振られた金貨には実質的な価値がない。
- **序盤の街に対して金貨1枚の価値が大きすぎる**：1万円は都市資金10万に相当し、7日目の街の収入（54/時）の約1,850時間分である。街は時間で決まる上限（発展Lv・建設時間・区画）に当たり、受け取った資源を使い切れない。
- **貯金を全額街に入れても、最終的な街はほぼ同じ**：同じ貯金スケジュール（累計20万円）を債券経由でおまかせ資源として入れても、60日目の人口は 3,053人（入れない場合 3,090人）だった。3日目は 37人 対 12人と速いものの、すぐに追いつかれる。
- **債券への交換が資源交換の上位互換**：債券が上限（月間自由予算 × 3）未満なら、金貨→債券は手数料なしで同じ資源がつき、発展倍率と精算の肩代わりもつく。手数料5Sを払って金貨→資源を選ぶ理由がない。B＝10万円なら上限は30万円で、多くの目標額はここに届かない。
- **銀貨の記録報酬は5日目以降ほぼ効かない**：1日上限300Sは都市資金300に相当する。街の収入に対して、5日目で約47%、10日目で約9%、20日目で約1.5%、30日目で約0.3%。

## 4. 進行と難易度曲線

発展Lvは17日目に上限の Lv6 に達し、要件の目安（3週間前後）より4日早い。それ以降の発展ptは区画の上限にしか効かず、その上限も効いていないため、中盤以降は時間発展と債券倍率が空回りする。

| 発展Lv | 要件の目安 | 実測 k=1 | 実測 k=1.5 |
|---|---|---|---|
| Lv2 村 | 1日目 | 1日目 | 1日目 |
| Lv3 町 | — | 3日目 | 3日目 |
| Lv4 地方都市 | 1週間前後 | 8日目 | 5日目 |
| Lv5 大都市 | — | 12日目 | 10日目 |
| Lv6 巨大都市 | 3週間前後 | 17日目 | 14日目 |

- **債券倍率 k は街の大きさに効かない**：k=1.5 でも Lv6 が3日早まるだけで、17・50・60日目の人口は k=1 と同じ（236人・2,579人・3,090人）。k は発展ptにしか掛からず、建設を止めているのは都市資金だからである。
- **区画の上限は効いていない**：60日目の上限152区画に対し、開いたのは45区画。開拓費が 1.2^n で増え、n=40 で都市資金約22万（収入の約15時間分）になるため、42日目以降はほぼ止まる。`MAX_PLOTS`＝400 には届かない。
- **序盤2日間はほぼ止まる**：交換しない場合、1〜2日目の人口は10人のまま。都市資金の収入が9/時で、木造住宅（都市資金160）や開拓（150）にほぼ丸一日かかる。最初の手応えはプレイヤーの交換次第である。
- **技術Lvは金額の絶対値で決まる**：20万円で全解放。目標が3万円なら技術Lv4止まりで、オフィス・高層住宅・未来都市センターは出ない。目標が100万円なら達成率20%で全解放し、残り80%は新しい建物が出ない。
- **長いシーズンは中盤以降の変化が少ない**：発展Lvは3週間、技術Lvは20万円で頭打ちになる。その後に増えるのは人口と建物Lvだけで、街の見た目も工場と道路が増えるだけになる（§5 B-07）。
- **銀行Lvの最大ボーナスは使えない**：+30% は達成率100%（シーズン終了の確認待ち）でしか得られない。

## 6. 改善提案

まず優先順と不足解消の2点（それぞれ数行の変更）を直すと、公共施設が建ち、7日目の停止もなくなることを試算で確かめた。そのうえで、交換を組み込んだ `balance.ts` でお金の価値を調整するのが次の段階である。
